# ogrenci-giris-paneli
Portal, öğrencilerin sınavlarına girmesini, derslerini takip etmesini ve not/puan hesaplamalarını yapmasını sağlayan modern ve etkileşimli bir web platformudur.
🚀 Öne Çıkan Özellikler
🔒 Güvenli Giriş Paneli:
Kurumsal E-Posta (ogrenci.edu.tr) veya Öğrenci Numarası ile oturum açma.
FaceID / TouchID desteği sağlayan Passkey (Biyometrik) doğrulama.
Şifre girilirken gözlerini kapatan interaktif sevimli maskot.
📝 Sınav Giriş & Takip Sistemi:
Aktif vize/final sınav tarihlerini ve kalan süreleri görüntüleme.
Güvenli online sınav ekranına tek tıkla erişim.
📚 Ders & Devamsızlık Takibi:
Dönemlik aktif ders listesi, akademisyen bilgisi ve derslik lokasyonları.
Canlı devamsızlık durumu oranı.
📊 Not & Puan Hesaplama Modülü:
Vize/Final yüzdelerine göre harf notu ve ANO/AGNO (GPA) ortalama hesaplayıcı.
Hedeflenen mezuniyet notu için simülasyon aracı.
📱 Tam Mobil (PWA) Desteği:
Tarayıcı üzerinden doğrudan cihaza indirilip mobil uygulama olarak kullanılabilir.
🛠️ Teknolojiler
Frontend: HTML5, Tailwind CSS, JavaScript (ES6+)
İkonlar & Fontlar: FontAwesome 6, Google Plus Jakarta Sans
Animasyonlar: Canvas 2D API & CSS3 Glassmorphism
